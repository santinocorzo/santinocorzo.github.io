# Portfolio Personal - Santino Corzo (v0.1)

Primera versión funcional de mi portfolio web personal, desarrollada para la materia **Aplicaciones Informáticas II (6º E - Instituto San Agustín)** y publicada mediante **GitHub Pages**.

## Sitio publicado
- **URL pública:** https://santinocorzo.github.io

## Estructura del proyecto
- `index.html`: Estructura semántica principal (encabezado, presentación, sobre mí, proyectos, habilidades, contacto y pie de página).
- `css/estilos.css`: Diseño visual minimalista con variables CSS, modelo de caja y tarjetas adaptables.
- `js/script.js`: Archivo preparado para interactividad en futuras versiones.
- `assets/img/`: Imágenes y capturas de los proyectos.
- `bitacora_ia.md`: Registro de consultas realizadas a inteligencia artificial y decisiones tomadas.
